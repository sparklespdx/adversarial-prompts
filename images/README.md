# Images Directory

This directory contains screenshots, diagrams, and other visual assets used in the adversarial prompt examples.

## Naming Convention

- Use descriptive names: `copilot-injection-example.png`
- Include dates for time-sensitive content: `chatgpt-jailbreak-2024-01.png`
- Use consistent file formats: PNG for screenshots, SVG for diagrams when possible

## Image Guidelines

- Keep file sizes reasonable (< 1MB when possible)
- Include alt text in markdown for accessibility
- Ensure no sensitive information is visible in screenshots
