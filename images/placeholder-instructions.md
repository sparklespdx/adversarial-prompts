`trail-of-bits-copilot-injection.png`

## Adding Your Own Images

1. Save your screenshot as a PNG file
2. Use descriptive naming: `technique-name-screenshot.png`
3. Update the markdown file to reference the actual image
4. Test that the link works in your markdown viewer

Example: Replace `trail-of-bits-copilot-injection-placeholder.txt` in the Trail of Bits example with an actual PNG screenshot when available.
