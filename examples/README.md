# Examples Directory

This directory contains documented examples of prompt injection, adversarial prompts, and other LLM security techniques.

## Structure

- Each example should be in its own markdown file
- Images and screenshots should be stored in the `/images` directory
- Use descriptive filenames and include dates when relevant

## Example Categories

- **Prompt Injection**: Direct attacks that override system prompts
- **Jailbreaking**: Techniques to bypass safety measures
- **Data Extraction**: Methods to extract training data or sensitive information
- **Code Injection**: Attacks targeting code generation models
- **Social Engineering**: Human-targeted attacks using LLM outputs
