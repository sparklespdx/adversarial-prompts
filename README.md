# Adversarial Prompts Collection

A curated collection of prompt injection examples, adversarial prompts, and other LLM security techniques for educational and research purposes.

## 🎯 Purpose

This repository documents various techniques used to exploit, test, and understand the limitations of Large Language Models (LLMs). All examples are provided for educational purposes to help developers, researchers, and security professionals better understand and defend against these attack vectors.

## 📁 Repository Structure

```
adversarial-prompts/
├── examples/           # Documented attack examples
├── images/            # Screenshots and visual assets
├── docs/              # Additional documentation
└── README.md          # This file
```

## 🧪 Example Categories

- **🎭 Prompt Injection**: Direct attacks that override system prompts
- **🔓 Jailbreaking**: Techniques to bypass safety measures and content filters
- **📊 Data Extraction**: Methods to extract training data or sensitive information
- **💻 Code Injection**: Attacks targeting code generation models (Copilot, CodeT5, etc.)
- **🎪 Social Engineering**: Human-targeted attacks using LLM outputs
- **🔍 Information Disclosure**: Techniques to reveal system prompts and internal logic
